# German terms of executive search

Use these terms when the consultant writes German. They are the words consultants in Austria, Germany and Switzerland use.

| English | German |
| --- | --- |
| mandate, search assignment | Mandat, Suchauftrag |
| executive search firm | Personalberatung, Executive-Search-Beratung |
| consultant, researcher | Berater, Researcher |
| client | Kunde, Auftraggeber |
| job description | Stellenbeschreibung |
| briefing | Briefing |
| candidate search | Kandidatensuche |
| search plan, search frame | Suchplan, Suchrahmen |
| target company list, origin area | Zielfirmenliste, Herkunftsbereich |
| search lane | Suchweg |
| depth: basic, standard, premium | Suchtiefe: basic, standard, premium |
| longlist, shortlist | Longlist, Shortlist |
| direct approach | Direktansprache |
| category: fit, reserve, exploratory | Einordnung: passend, Reserve, explorativ |
| tier (A to D) | Tier (A bis D) |
| speaks for, speaks against, not evidenced | spricht dafür, spricht dagegen, nicht belegt |
| must-have, nice-to-have | Muss-Kriterium, Kann-Kriterium |
| off-limits | Off-Limits |
| benchmark candidate | Benchmark-Kandidat |
| rejection | Ablehnung |
| second pass | zweiter Durchlauf |
| notice period | Kündigungsfrist |
| tenure | Verweildauer, Betriebszugehörigkeit |
| seniority | Seniorität, Führungsebene |
| verified business contact | verifizierter geschäftlicher Kontakt |
| credits | Credits |
| credit balance | Credit-Guthaben |
| booking | Buchung |
| buy credits | Credits kaufen |
